Stumps Scorebook - installable cricket scorer

Put all files in this folder on any free web host (GitHub Pages, Netlify, Cloudflare Pages).
Open the web address on your phone, then:
  Android (Chrome): menu > Install app / Add to Home screen
  iPhone (Safari):  Share > Add to Home Screen
It then opens like a normal app, works offline and saves records on the phone.
Use Teams > Backup to phone regularly to keep a safe copy.
